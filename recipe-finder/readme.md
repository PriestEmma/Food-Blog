# 🍽️ Recipe Finder

A responsive recipe finder built with HTML, CSS, and vanilla JavaScript. Search for meals, filter results by category, and explore recipes with their ingredients, measurements, and cooking instructions using TheMealDB API.

🔗 **Live Demo:** [View Recipe Finder](https://foodbloga2.netlify.app)

## ✨ Features

- 🔍 **Search Recipes** — Find meals by name.
- 🗂️ **Category Filtering** — Filter recipes by meal category.
- 🍲 **Recipe Cards** — View meal images, names, categories, and cuisine areas.
- 📖 **Recipe Details** — Open a recipe to view its ingredients, measurements, and cooking instructions.
- 🔄 **Dynamic Views** — Switch between recipe details and search results.
- ⏳ **Status Messages** — Display loading, empty-result, and error messages where handled.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- [TheMealDB API](https://www.themealdb.com/api.php)
- Fetch API, Promises, and Async/Await
- DOM Manipulation and Event Delegation

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🌐 API

This project uses [TheMealDB API](https://www.themealdb.com/api.php) to retrieve recipe data.

| Endpoint         | Purpose                  |
| ---------------- | ------------------------ |
| `search.php?s=`  | Search meals by name     |
| `categories.php` | Retrieve meal categories |
| `lookup.php?i=`  | Retrieve a meal by ID    |
