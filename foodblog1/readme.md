# 🍔 FoodBlog

A responsive food blog / restaurant landing page featuring a hero carousel, popular dishes, menu, customer reviews, and an order form — built with HTML, CSS, and JavaScript, using Swiper.js for carousels.

🔗 **Live Site:** [foodbloga1.netlify.app](https://foodbloga1.netlify.app/)

## Features

- 🍽️ Hero carousel showcasing special dishes (Swiper.js)
- ⭐ Customer reviews carousel with responsive breakpoints (1 / 2 / 3 per view)
- 🍕 Popular dishes and menu sections with ratings and pricing
- 📝 Order form for customer requests
- 🍔 Custom page loader while assets load
- 📱 Fully responsive layout with mobile navigation

## Built With

- HTML5
- CSS3
- JavaScript
- [Swiper.js](https://swiperjs.com/)
- [Font Awesome](https://fontawesome.com/) for icons

## Sections

- **Home** — Hero carousel with featured dishes
- **Dishes** — Popular dishes grid
- **About** — Why choose us
- **Menu** — Today's specialty items
- **Review** — Customer testimonials carousel
- **Order** — Order form for customers
